地图服务配置说明

公开分享前，需要给高德 JS API 配置受域名限制的 Key，并把 securityJsCode 放在服务端代理。此站点是静态网页，不能安全保存服务端密钥。

  1. 在高德控制台为 JS API Key 配置允许访问的域名：phlinh0091-ai.github.io。浏览器中的 Key 会公开可见，因此必须限制域名。
  2. 在 Cloudflare Workers 免费计划部署仓库里的 workers/amap-proxy/src/index.js，将 ALLOWED_ORIGIN 设为 https://phlinh0091-ai.github.io。
  3. 在 Worker 的 Secret 设置中保存 AMAP_SECURITY_CODE。不要把它写进仓库、网页或聊天。
  4. 把 Worker 的服务地址填到 map-config.js 的 serviceHost，格式为 https://你的Worker域名/_AMapService；把受域名限制的 JS API Key 填到 amapKey。
  5. 提交配置后，GitHub Actions 才能部署可用地图。朋友打开同一网址即可浏览；定位只在点击后请求。

如果尚未配置代理，页面仍能显示项目材料，但地图和定位功能不会工作。Cloudflare Workers 免费额度有上限；GitHub Pages 与高德服务也各自受平台规则和额度约束。
